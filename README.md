# 🌅 Morning Bot — утренний Telegram-бот

Бот присылает сводку каждый день в **07:30**: погода, рекомендация одежды (через GPT), расписание уроков и задачи на день.

## Быстрый старт

### 1. Получи токены

| Ключ | Где получить |
|------|-------------|
| `TELOXIDE_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `OPENWEATHER_API_KEY` | [openweathermap.org](https://openweathermap.org/api) → Free tier |
| `OPENAI_API_KEY` | [platform.openai.com](https://platform.openai.com/api-keys) |

### 2. Создай `.env` файл

```bash
cp .env.example .env
# Открой .env и вставь свои ключи
```

### 3. Запусти

```bash
cargo run --release
```

---

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Первый запуск — запрашивает геолокацию |
| `/now` | Получить сводку прямо сейчас |
| `/урок Пн 08:30 Математика` | Добавить урок в расписание |
| `/расписание` | Показать расписание на неделю |
| `/очистить` | Очистить всё расписание |
| `/задача Купить хлеб` | Добавить задачу на сегодня |
| `/задачана 2024-12-25 Текст` | Добавить задачу на конкретную дату |
| `/задачи` | Показать задачи на сегодня |
| `/готово 3` | Отметить задачу #3 выполненной |
| `/удалить 3` | Удалить задачу #3 |

## Как устроен проект

```
src/
├── main.rs        — точка входа, диспатчер
├── db.rs          — SQLite: пользователи, расписание, задачи
├── weather.rs     — OpenWeatherMap API
├── openai.rs      — GPT-4o-mini для рекомендаций одежды
├── scheduler.rs   — крон-задача 07:30, сборка сводки
└── handlers.rs    — все команды бота
```
